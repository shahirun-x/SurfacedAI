# Surfaced.ai

Surfaced.ai is a content optimization audit tool designed to evaluate content across SEO, AEO, GEO, AIO, and Technical pillars to see if it actually gets found.

## Getting Started

First, install dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Project Structure

- `src/app/`: Next.js App Router routes and layouts
- `src/components/`: Reusable UI components
- `src/lib/analysis/`: Rule-based analysis engine
- `src/lib/utils/`: Shared helper functions and utilities
- `src/types/`: TypeScript type definitions and interfaces
